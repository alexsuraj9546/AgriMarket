# AgriMarket
Agrimarket is an AI-powered agriculture platform featuring crop disease detection, smart chatbot assistance, real-time weather alerts, and a digital marketplace to empower farmers with modern technology.
User → Frontend (React / Next.js)
         ↓
Backend (Node.js + Express)
         ↓
MongoDB Database
         ↓
AI Model (Python - TensorFlow)
         ↓
Weather API Integration
AI-Powered Smart Agriculture Ecosystem

Installation Guide
1️⃣ Clone Repository
git clone https://github.com/your-username/agrimarket.git
cd agrimarket

2️⃣ Setup Frontend
cd frontend
npm install
npm run dev

3️⃣ Setup Backend
cd backend
npm install
npm start

4️⃣ Environment Variables

Create .env file:

MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
WEATHER_API_KEY=your_api_key
